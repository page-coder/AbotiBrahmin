# AbotiBrahmin — Bilingual Digital Heritage Encyclopedia

A production-ready static website dedicated to documenting the history, traditions, sacred geography, gotras, surnames, and social development of the Aboti Brahmin community of Dwarka, Porbandar, and Saurashtra (Gujarat, India).

## Technical Specifications
- **Technology:** Semantic HTML5, Modular CSS3, Vanilla ES6 JavaScript.
- **Hosting:** 100% compatible with free GitHub Pages.
- **Dependencies:** None. Zero external build steps, no backend, no mandatory API keys, no server runtime required.
- **Bilingual Engine:** Complete English and Gujarati support with real-time toggle and persistent user preference.
- **Client-Side Search:** Instant modal search indexing all chapters, summaries, and key terms in both languages.
